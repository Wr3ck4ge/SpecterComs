## Default Permission

Allows access to all specter-audio plugin commands

#### This default permission set includes the following:

- `allow-list-audio-devices`
- `allow-list-output-devices`
- `allow-start-capture`
- `allow-stop-capture`
- `allow-play-frame`
- `allow-set-output-device`
